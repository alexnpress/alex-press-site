ALEX PRESS — WEBSITE
====================
Live at https://alexnpress.net (hosted free on GitHub Pages).


WHAT'S IN THIS FOLDER
---------------------
index.html          The "About Me" landing page (bio and photo)
contact.html        The Contact page (email, Twitter, Instagram)
work.html           The Work page (publications and podcasts)
style.css           All the design (fonts, colors, spacing) for every page
images/headshot.jpg The photo on the About Me page
CNAME               Tells GitHub the site's address. Don't delete or edit it.
README.txt          This file


HOW UPDATES WORK
----------------
Any change saved to the "main" branch on GitHub goes live automatically,
usually within a minute or two.


TO CHANGE ANY OF THE WRITING
----------------------------
Open the .html file and type over the words. Anything between < and > is
code. Leave that alone and only change the plain English between them.


TO CHANGE THE PHOTO
-------------------
Replace images/headshot.jpg with a new photo saved under exactly the same
name.


TO CHANGE HOW IT LOOKS
----------------------
Everything visual is in style.css. The font is set near the top; a few
alternatives (Arial, Helvetica, Georgia) sit there switched off. The font
size is "font-size: 16px", which is exactly 12 point.

After changing style.css, bump the number in "style.css?v=4" at the top of
each .html file (to v=5, and so on) so browsers load the new version.
